# DEV36 — 사용자 실기 PDF 124페이지 점검 및 학교안심 글꼴 전환

기준일: 2026-11-15 KST. **이 문서는 개인 문서의 제목·위치·사업명·본문을 공개하지 않는 집계 보고서**다. 실제 사용자별 검수 원본·전체 문서명·내용은 GitHub에 등록하지 않는다.

## 실제 제출 PDF 검사 결과

- 사용자 변환결과 ZIP 1개 안의 PDF 8개: 총 **124페이지**. PyMuPDF로 문서 오픈 및 모든 페이지 저해상도 렌더 성공.
- 117쪽에서 텍스트 추출 가능, **7쪽은 실제 렌더에서도 공백** (각 PDF의 2쪽/마지막 쪽 일부). 간지인지 원본 누락인지 원본 HWP/HWPX가 없으면 판단 불가. 자동 삭제 금지.
- PDF 이미지 객체 참조 합계 **49**, 벡터 드로잉 합계 **9,164**. 각 건은 참조/경로 합계이며 그림이 원본과 동일하다는 증거 아님.
- 검사한 임베딩 글꼴 객체의 임베딩 누락 **0**. PDF 내 글꼴이 포함됐다는 사실은 원본 지정 서체가 정확히 보존됐다는 의미가 아님.
- 머리말/꼬리말·페이지 번호 반복 구조, 다중 테이블, 도면/그림 배치가 렌더에 존재. 특정 헤더 문구의 내부 불일치 및 출력 페이지 범위와 이름 범위 불일치가 발견됐으나 원본과 대조 전까지 원본 오기/변환 버그 판별 불가.
- 이 자료는 **이미 PDF로 변환된 8개 결과**이므로 현재 웹 엔진으로 25개 HWP/HWPX를 재실행한 결과라고 표시하지 않는다.

## 글꼴 출처/검증/한계

사용자 제출 안심글꼴 ZIP에서 검출된 **KERIS 학교안심 바른바탕 R/B, 바른돋움 R/B 4개**를 실무용 기본 후보로 선정. 각각의 SHA-256은 프로젝트 `browser-local/scripts/install-safe-fonts.mjs`에 고정했고 4개 공개 LFS 원본 오브젝트 해시와 대조했다.

**브라우저 PDF 글꼴 정책**: 문서의 실제 원본 파일(사용자가 선택한 TTF/OTF) > 허용된 설치 글꼴 > 자체 사이트에 번들된 학교안심 OFL 글꼴. 기호 누락 보완용으로 Google OFL `NotoSansSymbols2-Regular.ttf` 1개를 선택했다. 서체 대체는 행간·표 셀/페이지 줄바꿈을 변경할 수 있다.

실제 변환 PDF를 검사했을 때 KERIS 4종에 없는 문자로 `◦`, `•`, `‧`, `▸` 등 다수의 특수기호가 검출됐다. 기호용 1종으로 모든 문자를 보존한다고 단정하지 않는다. **기호 글리프 커버리지와 브라우저 실제 출력은 별도 수락 조건**이다.

KERIS 학교안심 공식 라이선스는 웹사이트·UI·재배포·임베딩을 허용한다.
- 바른돋움: https://copyright.keris.or.kr/wft/fntDwnldView?fntGrpId=GFT202301110000000000001
- 바른바탕: https://copyright.keris.or.kr/wft/fntDwnldView?fntGrpId=GFT202301120000000000002
- Noto symbols OFL: https://github.com/notofonts/symbols

## DEV36 코드 변경

- 기존 6개 Nanum/Sunrise 폰트 바이너리 **개발 브랜치에서 제거**.
