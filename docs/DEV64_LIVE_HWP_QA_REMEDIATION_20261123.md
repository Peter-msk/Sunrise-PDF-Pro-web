- 원인 규명 수준: '일반 예외의 코드 유실' 경로는 소스 확인·보완, 원본 특정 서식/그림의 실질 오류는 재현 입력이 없어 미확정.

## 2. 수행한 수정
- svg-runtime-error.mjs: 알 수 없는 그림 효과 처리 예외를 SVG_FILTER_PIPELINE_FAILED로 안전하게 분류하며 원본 Error는 브라우저 내 cause로 보존. 지원하지 않는 필터 등 기존 코드와 취소 오류는 변경하지 않음.
- converter.js: 오류를 구분하지 못했던 SVG 효과 처리 catch에 단계·쪽 번호 기반의 고정 오류 부여.
- svg-professional.js: SVGtoPDF·PDFKit 그림 렌더링 중 별도 기계 오류 코드 없이 발생하는 예외를 SVG_VECTOR_RENDER_FAILED로 분류. 기존 PDF_STREAM_TIMEOUT 등 알려진 코드 보존, 중도 PDF 결과 폐기 및 AbortError 유지.
- conversion-recovery.mjs: 위 두 오류만 기본 벡터 방식 실패 시 '이 파일만 이미지 PDF로 복구'를 명시적으로 제공. 기존 SVG_FILTER_EFFECT_UNSUPPORTED는 여전히 혼합 PDF 복구 우선.
- main.js: 실패 파일의 마지막 처리 페이지를 숫자로 표시. 명시적 재시도 시 진행 진단 이벤트 계수 초기화.
- tests/dev64-real-qa-error-recovery.mjs: 원문 노출 방지, 취소/기존 오류 불변, 단일 파일 복구, 기본 품질 자동 강등 없음의 회귀 검사 추가.
