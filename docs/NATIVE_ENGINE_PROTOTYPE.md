# 한컴 및 Office PDF 변환 개발용 실험

이 코드는 **로컬 실험 단계**이며 웹 서비스나 운영 서버가 아니다. 클라우드 Worker에서 실행할 수 없고, API·업로드·큐·사용자 격리·외부 네트워크 차단·악성 파일 격리는 구현되지 않았다. 신뢰하지 않는 문서나 실제 고객 문서를 사용하지 말 것. 입력 파일은 네트워크에 전송되지 않지만 Office 엔진 내부의 외부 링크 접근 자체를 차단하는 샌드박스는 없다.

## 엔진 분리

- HWP/HWPX: Windows에 설치된 정식 한컴오피스의 COM 오토메이션 `Open` 및 `SaveAs(..., "PDF", ...)` 호출. 이 저장소에 한컴 프로그램이나 글꼴은 포함되지 않는다. 설치된 라이선스, 자동화 사용 권한 및 보안 모듈은 운영자가 별도로 확인·구성해야 한다. 본 개발 환경은 Windows/한컴이 없으므로 실제 실행은 미검증이다. 자동화 프로세스 중단·대화상자·거절 문서 처리와 격리를 해결하기 전 서버에 노출하지 않는다.
- XLS/XLSX, PPT/PPTX, DOC/DOCX: 별도 LibreOffice 프로세스의 Calc/Impress/Writer PDF 필터. 형식별 원본 fidelity는 실문서 대조 전 보장하지 않는다. 최초 실험 환경은 LibreOfficeDev 26.8 alpha이며, 운영 엔진으로 승인된 안정판이 아니다.
- JPG/PNG: 이 실험에서 다루지 않으며 기존 브라우저 이미지 엔진을 사용한다.

## 로컬 합성 문서 검사

`python -m unittest discover -s tests -v`는 임시 Excel 1쪽·PowerPoint 2쪽을 직접 만들고 PDF 쪽수와 텍스트를 확인한다. 원본 대비 시각 충실도, xls/ppt/doc/docx 및 실제 업무 문서 시험은 별도다.

개발자가 인지한 문서로 수동 실행: `python scripts/office_pdf_probe.py sample.pptx output.pdf`. 원본 덮어쓰기는 차단하고 변환 임시 디렉터리는 종료 시 삭제한다. 사용자의 실문서는 저장소나 테스트 아티팩트에 추가하지 않는다.

## 웹 연동 전 필수 작업

1. 공식 한컴 제품/오토메이션의 상용 및 서버 이용 권한과 라이선스, Windows 전용 실행 환경 확보.
2. 안정적인 LibreOffice 버전 고정 및 Office 문서별 그림·표·차트·페이지·슬라이드 크기·폰트 검증.
3. 원본·출력 격리 보관, 접근권한, 암호화 전송, 보존/삭제 정책, 작업별 샌드박스와 자원·시간 제한, 매크로 및 외부 접속 차단, 잔여 프로세스 정리.
4. 사용자에게 원본이 서버에 전송된다는 사실을 명확히 알린 뒤 업로드/다운로드/취소/오류 처리를 실제 연결. 현재 웹은 브라우저에서만 처리하므로 그 개인정보 처리 방식과 충돌한다.
5. 실제 사용자 문서와 한컴/Excel/PowerPoint에서 저장한 기준 PDF를 페이지별로 대조. 없거나 재배포할 수 없는 글꼴은 정확히 표시한다. 임의 대체를 원본과 동일하다고 표시하지 않는다.
