# PDF 원본 기준 비교 도구

한컴 등에서 직접 출력한 기준 PDF와 웹 변환 결과 PDF를 **로컬에서** 비교한다. 문서를 전송하지 않으며 JSON에는 파일명이나 문서 본문을 기록하지 않는다.

Python과 PyMuPDF가 설치된 환경에서 저장소 루트에서 실행한다.

```bash
python scripts/compare_pdf_reference.py reference.pdf candidate.pdf --output comparison.json
python -m unittest discover -s tests -p 'test_compare_pdf_reference.py' -v
```

페이지 수, 회전, 용지 크기, 추출 문자 수·유사도와 회색조 렌더링의 평균 차이를 표시한다. 용지 크기가 다르거나 기준 해상도로 1,600만 픽셀을 초과하면 픽셀 비교를 생략한다. 문자 유사도는 쪽당 앞 2만 자까지만 검사하며 생략 여부를 기록한다. 공백을 정규화하므로 원문 서식 비교가 아니다. 이미지 차이 점수는 작을수록 유사하지만 허용 기준을 나타내지는 않는다. 출력 PDF가 스캔 이미지인 경우 문자가 없을 수 있다.

이 도구의 수치는 검토 대상을 찾기 위한 지표이며 합격 판정이나 원본과의 동등성을 의미하지 않는다. 글꼴·문자 위치·표·도형·그림·주석·페이지 분할은 사람이 원본과 모든 출력 페이지를 직접 비교해야 한다. 기본값은 96 DPI이며 36~200 범위에서 `--dpi`로 조절한다. 실제 업무 원본과 한컴 기준 PDF는 이 도구에 포함되지 않는다.
