# Sunrise PDF PRO(Web) — OFL 기본 서체 고지

## 학교안심 글꼴 — KERIS(한국교육학술정보원)

- 저작권자: KERIS. 제작사: 윤디자인.
- 사용 서체: **학교안심 바른바탕 R/B, 학교안심 바른돋움 R/B** (TTF 4개).
- 이용조건: OFL(Open Font License). 문서, 웹사이트, PDF 임베딩, 재배포 및 상업적 이용은 KERIS 공식 안내에 따라 허용되며, 글꼴 자체의 유료 판매는 금지.
- 공식 출처(돋움): https://copyright.keris.or.kr/wft/fntDwnldView?fntGrpId=GFT202301110000000000001
- 공식 출처(바탕): https://copyright.keris.or.kr/wft/fntDwnldView?fntGrpId=GFT202301120000000000002
- 원본 바이트는 사용자가 제공한 ‘안심글꼴’ ZIP의 개별 TTF에서 SHA-256을 확인했으며, 고정 커밋의 LFS 미러에서 **빌드 시에만** 받습니다. 파일 크기와 SHA-256이 다르면 빌드가 중단됩니다.
- 설치형 한컴오피스가 필요한 것이 아닙니다. PDF 출력의 서체 대체는 원본 서체와 동일한 모양/줄바꿈을 보장하지 않습니다.

## Noto Sans Symbols 2 — Google

- 저작권: Google (Noto Fonts project)
- 사용 서체: NotoSansSymbols2-Regular.ttf — **본문 서체가 표시할 수 없는 특수기호를 위한 보완용 1개**.
- 라이선스: SIL OFL 1.1. 기본 서체의 한글 디자인을 대체하기 위한 것이 아니며 기호 누락을 완화합니다.
- 프로젝트 출처: https://github.com/notofonts/symbols
- 빌드 출처(고정): https://github.com/edwardkim/rhwp/blob/7213ed1f96266b95e22cd5645a07851c9c18298e/assets/fonts/NotoSansSymbols2-Regular.ttf
- 배포 파일은 Git blob SHA-1 + 크기로 검증합니다.

라이선스 전문은 같은 폴더의 `SIL-OFL-1.1.txt` 파일을 참고하세요.

## 데이터 보호와 배포 경계

- 문서, 폰트 내용, 원본 HWP/HWPX 파일은 Cloudflare로 전송되지 않습니다.
- **폰트 다운로드는 배포 빌드 단계에서만** 실행됩니다. 운영 브라우저는 검증 후 함께 배포된 동일 출처의 정적 TTF만 요청합니다.
- 기존 NanumGothic/NanumMyeongjo/SunriseSymbols/SunriseMarks는 운영 파일 집합에서 제외합니다.
- 기타 안심글꼴은 라이선스와 웹 임베딩 조건을 개별 검증하지 않았으므로 임의로 일괄 배포하지 않습니다.
